# 🚀 Mini Web Projects (HTML • CSS • JavaScript)

This repository contains a collection of **beginner-friendly web development projects** built using **HTML, CSS, and JavaScript**.
The goal of these projects is to strengthen core frontend development concepts such as **DOM manipulation, API usage, responsive design, and user interaction**.

These projects are part of my journey to becoming a **full-stack developer and software engineer**.

---

## 📂 Projects Included

### ✅ 1. To-Do List App

A simple and interactive task management application.

**Features**

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Dynamic DOM updates

**Concepts Practiced**

* DOM manipulation
* Event listeners
* Local state handling

---

### 🌦️ 2. Weather App

A web application that shows **real-time weather information** for any city.

**Features**

* Search weather by city name
* Displays temperature, weather condition, and location
* Fetches live data from a weather API

**Concepts Practiced**

* API fetching
* Async JavaScript (`fetch`)
* JSON data handling

---
